# AURELIA

### The World, Within Reach.

> **Aurelia is a UI-based front-end web project** focused on creating a clean, elegant, and user-friendly interface for exploring newspapers and media sources from different countries.

The main focus of this project is **UI design and front-end development using HTML and CSS**, with JavaScript used for small interactive features such as the navigation menu and page transitions.

---

## ✨ Features

### 🌍 Country & Language Based Sections

Aurelia provides separate sections for different languages and regions.

Currently, the project includes:

- 🇺🇸 English Newspapers
- 🇪🇸 Spanish Newspapers
- 🇧🇩 Bangla Newspapers
- 🇮🇳 Hindi Newspapers

### 📰 Newspaper Cards

Each newspaper is presented using a clean card-based UI containing:

- Newspaper image
- Newspaper name
- Short description
- Read More button
- Direct link to the official website

### ☰ Animated Navigation

The website includes a hamburger navigation menu.

JavaScript is used to open and close the menu, while CSS transitions make the movement smooth.

### 🔗 About & Contact Section

The website also contains an About and Contact section with links to:

- GitHub
- LinkedIn
- Email

### 🎨 UI & Visual Design

The project focuses on:

- Clean layouts
- CSS Grid
- Flexbox
- Responsive structure
- Custom typography
- Consistent color palette
- Smooth transitions
- Minimal editorial-style design

## 🚀 How to Run

### Method 1 — Open Directly

Open `index.html` in any modern web browser.

### Method 2 — VS Code Live Server

1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Open `index.html`.
4. Right-click inside the file.
5. Select **Open with Live Server**.
6. The website will open automatically in your browser.
